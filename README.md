# טיול מסע ארה״ב וקנדה 2027

מדריך טיול אישי, אתר סטטי (PWA) בעברית, מימין לשמאל, שעובד גם בלי קליטה.
המסלול: סן פרנסיסקו · הר ריינייר · סיאטל · קרוז אלסקה · הרוקיז הקנדיים · לוס אנג׳לס, 19.8–15.9.2027.

האתר החי: https://omrisapir12344-png.github.io/USACANADA/

## מבנה

| נתיב | מה יש שם |
|---|---|
| `index.html`, `css/`, `js/` | האתר עצמו, בלי שלב build |
| `data/trip.json` | כל נתוני הטיול: אזורים, ימים, מקומות ומדריכים, טיסות, מלונות, משימות ותקציב |
| `data/routes.json` | ק״מ וזמני נסיעה לכל יום (נוצר ע״י `scripts/fetch-routes.py`) |
| `data/credits.json` | קרדיטים לכל תמונה (נוצר ע״י `scripts/fetch-images.py`) |
| `assets/img/<id>/` | תמונות מ־Wikimedia Commons ברישיון חופשי, WebP ברוחב 1200 |
| `vendor/` | Leaflet 1.9.4 והגופן IBM Plex Sans Hebrew, מוטמעים מקומית בשביל אופליין |
| `sw.js`, `manifest.json` | שמירה לאופליין והתקנה כאפליקציה |

אין בריפו מפתחות או טוקנים. מפות: OpenStreetMap ו־Leaflet. מרחקים: OSRM. תחזית: Open-Meteo. אף אחד מהם לא דורש מפתח.
אין בנתונים מספרי הזמנה, קודים סודיים, פרטי דרכון, שמות נוסעים או אמצעי תשלום.

## עדכון התוכן

**מהאתר (מצב עריכה):**
1. עוד ← אופליין ועריכה ← הפעלת מצב עריכה.
2. עורכים נקודות במפה, משימות, מלונות או תקציב. השינויים נשמרים כטיוטה במכשיר הזה בלבד.
3. ייצוא trip.json, ואז מחליפים את `data/trip.json` בריפו ב־GitHub (Add file ← Upload files, או עריכת הקובץ).
4. GitHub Pages מעדכן את האתר תוך כמה דקות.

עריכה במכשיר לא מגיעה לצופים עד שמפרסמים. מצב עריכה הוא לא הרשאת אבטחה: כל מי שיש לו את הקישור רואה הכול.

**סקריפטים (חד־פעמיים, בלי מפתח):**
- `python3 scripts/fetch-images.py` מוריד תמונות שחסרות. Wikimedia מגביל קצב, אז זה איטי, והסקריפט ממשיך אחרי הפסקות.
- `python3 scripts/fetch-routes.py` מחשב מחדש ק״מ וזמני נסיעה אחרי שינוי מסלול.

## סנכרון בין טלפונים

אין שרת ואין מפתחות. בעמוד ״סנכרון עם בן/בת הזוג״ יוצרים קישור שמכיל את העדכונים (משימות, ״ביקרנו״, הערות, אריזה, הוצאות), שולחים בוואטסאפ, ובטלפון השני הקישור ממוזג אוטומטית. בהתנגשות נשמר השינוי האחרון. תמונות לא עוברות.
